# Real Adventure Riders

A public adventure motorcycling satire blog. All riders and stories are fictional, and the photographs are AI generated.

The website is in docs/. Publish with GitHub Pages from the main branch and the /docs folder. The repository contains 22 stories and 29 photos, with full size and thumbnail copies.

To update text, edit posts.json and run python build.py. Existing compressed photos are retained. New original photos can be placed in the sibling output/pannier-papers directory; new images require Pillow.

The blog is intended for realadventureriders.com. Set the custom domain in GitHub Pages settings before changing DNS.
